# Security

Never post Rancher API tokens, kubeconfig files, real endpoint details or confidential screenshots in public issues. Use synthetic examples and redact logs.

This extension stores generated kubeconfig credentials locally. Protect the device, plugin directory and backups. Archive/removal does not revoke credentials at Rancher. Review and revoke no-longer-needed credentials through your administrator.

For a suspected vulnerability, contact the repository owner privately rather than disclosing exploit details publicly. Do not create live credentials for test reports.
